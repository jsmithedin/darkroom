# Darkroom Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a self-hosted film photography tracker (REST API, React PWA, authenticated MCP server) that replaces the "Film Photography Tracker v2" Google Sheet.

**Architecture:** One FastAPI app serves the built React frontend, `/api` and `/mcp`. A single service layer owns every derived figure and invariant; REST routes and MCP tools are thin adapters over it. The app is its own OAuth authorization server for MCP clients and uses Google OIDC for people. Postgres holds everything.

**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy 2 async + asyncpg, Alembic, Pydantic v2, Authlib (Google client only), `mcp` 2.3.x (`MCPServer`), uv, ruff, mypy, pytest + testcontainers; React + TypeScript + Vite, TanStack Query, Chart.js; Docker Compose, PostgreSQL 16.

**Spec:** `docs/superpowers/specs/2026-11-22-darkroom-design.md`

## Global Constraints

- Python 3.12+; PostgreSQL 16+; no SQLite anywhere, tests use a real Postgres.
- Money is integer pence; lengths are integer millimetres; no floats for either. EI is `numeric(7,2)`.
- Defaults: `leader_mm = 250`, `frame_pitch_mm = 38`, `timezone = "Europe/London"`. Settings live in the DB.
- Stock can never go negative; checks run under `pg_advisory_xact_lock` per (film, format).
- Imported rolls (dated on or before 2026-11-22) have `counts_against_stock = false`; opening movements are dated 2026-11-22; zero openings are skipped.
- Scopes are `films:read` and `films:write`; `films:write` implies `films:read`. No delete tools in MCP.
- Every table has `id uuid`, `created_at`, `updated_at`, `created_by`, `updated_by` (audit_events, import_ledger, auth token tables excepted where noted).
- Cookies: `Secure; HttpOnly; SameSite=Lax`; CSRF header `X-CSRF-Token` on unsafe cookie-authed requests.
- External URLs come from `PUBLIC_BASE_URL`, never from request headers. Forwarded headers are trusted only from the tunnel network.
- Compose publishes no ports; services join the existing external cloudflared network.
- Touch targets at least 44px; inputs 16px; light/dark follow system. No component library. No multi-tenancy, queues, Redis.
- Secrets come from env or Docker secrets; `.env.example` is committed, real values never.
- Pin `mcp>=2.3,<3`.

## Review Focus

1. Logging a roll for a film/format with no stock returns a clear 409 naming the film and format, not a 500 (Task 3.3).
2. A bulk load larger than the metres left on the spool is allowed, and `exposures_left` floors at 0 instead of going negative (Task 3.1, 3.4).
3. Between 00:00 and 01:00 British Summer Time, "today" and "current month" use London time, not UTC (Task 5.2).
4. Running the import twice, or with a camera/film name missing from Lists, never duplicates or half-imports: it inserts nothing the second time and aborts listing every unknown name (Task 4.2).
5. A read-only token calling any write tool, a revoked or expired token, and a replayed (already-rotated) refresh token are all refused (Tasks 1.2, 6.3, 6.6).
